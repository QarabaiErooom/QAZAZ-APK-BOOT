## 🌌 Жалпы шолу

**QAZAZ APK Store Bot** — Telegram-дағы ең заманауи APK-дүкені боты. Бот Aiogram 3.7+ фреймворкы негізінде жасалған, SQLite деректер қоры мен Pillow кескін өңдеу кітапханасын пайдаланады.

```
┌──────────────────────────────────────────────────────────────────┐
│                     QAZAZ  ECOSYSTEM                             │
│                                                                  │
│   ┌─────────┐       ┌──────────────┐       ┌──────────────┐     │
│   │  ADMIN  │──────▶│   BOT CORE   │──────▶│   CHANNEL    │     │
│   └─────────┘       │              │       └──────────────┘     │
│        │            │  ▸ SQLite DB │              │              │
│        │            │  ▸ FSM State │              ▼              │
│   7-Step FSM        │  ▸ SHA-256   │       ┌──────────────┐     │
│   APK Upload        │  ▸ Preview   │       │    USERS     │     │
│   Broadcast         │    Gen 1080p │       │  Deep-link   │     │
│   Statistics        └──────────────┘       │  Download    │     │
│                                            └──────────────┘     │
└──────────────────────────────────────────────────────────────────┘
```

## ⚡ Мүмкіндіктер

### 🔐 Әкімші панелі

| Мүмкіндік | Сипаттама |
|:---|:---|
| 🚀 **7 қадамдық FSM** | APK → Иконка → Атауы → Сипаттамасы → Нұсқасы → Мод мүмкіндіктері → Санат |
| 🖼️ **Auto-Preview** | Иконкадан 1920×1080 preview автоматты генерациясы |
| 📢 **Арнаға пост** | HTML caption + Download deep-link бар әдемі жариялым |
| 📊 **Статистика** | Пайдаланушы / Қолданба / Ең көп жүктелген |

| 🔧 **Арналар басқару** | Міндетті жазылу арналарын динамикалық қосу/жою |

## 🚀 Орнату

### 1️⃣ Репозиторийді клондаңыз

```bash
git clone https://github.com/your-username/qazaz-apk-bot.git
cd qazaz-apk-bot
```

### 2️⃣ Тәуелділіктерді орнатыңыз

```bash
pip install aiogram pillow
```

### 3️⃣ Assets дайындаңыз

```
assets/
├── logo.png   ← Сіздің логотипіңіз  (кез-келген өлшем, PNG/RGBA)
├── badge.png  ← Сіздің badge іңіз   (кез-келген өлшем, PNG/RGBA)
└── font.ttf   ← TrueType шрифт файлы
```

> **💡 Кеңес:** Логотип биіктігі `140px`-тен үлкен болса, бот оны автоматты масштабтайды.

### 4️⃣ Конфигурацияны баптаңыз

`main.py` файлының жоғарғы бөлігіндегі `CONFIG` бөлімін өзгертіңіз:

```python
# =========================
# CONFIG
# =========================
BOT_TOKEN  = "YOUR_BOT_TOKEN_HERE"    # @BotFather-дан алыңыз
ADMIN_ID   = 123456789                # Сіздің Telegram User ID-іңіз
CHANNEL_ID = -100xxxxxxxxxx           # Постар жарияланатын арна ID-і
```

> **🔑 BOT_TOKEN алу:** Telegram-да [@BotFather](https://t.me/BotFather) ашып, `/newbot` командасын жіберіңіз.
>
> **🆔 ADMIN_ID алу:** [@userinfobot](https://t.me/userinfobot) арқылы өз ID-іңізді біліңіз.

### 5️⃣ Іске қосыңыз

```bash
python main.py
```

Бот сәтті іске қосылса, консольде мынаны көресіз:

```
INFO | Бот іске қосылды: @your_bot_username
```

## ⚙️ Конфигурация анықтамасы

| Параметр | Тип | Сипаттама | Мысал |
|:---|:---|:---|:---|
| `BOT_TOKEN` | `str` | Telegram Bot API токені | `"123456:ABC-DEF..."` |
| `ADMIN_ID` | `int` | Әкімшінің Telegram ID-і | `6302964967` |
| `CHANNEL_ID` | `int` | Пост жарияланатын арна ID-і | `-1003710265294` |
| `DB_PATH` | `str` | SQLite файлының жолы | `"apk_store.db"` |
| `PREVIEW_W` | `int` | Preview суретінің ені | `1920` |
| `PREVIEW_H` | `int` | Preview суретінің биіктігі | `1080` |
| `PREVIEW_BG` | `tuple` | Preview фон түсі (RGB) | `(0, 0, 51)` |
| `MAX_BYTES_TO_HASH` | `int` | SHA-256 лимиті (байт) | `26214400` (25 МБ) |
| `SLOGAN` | `str` | Caption соңындағы ұран | `"QAZAZ: Стандарттан тыс..."` |

## 🗄️ Деректер қоры схемасы

```sql
-- 📡 Міндетті жазылу арналары
CREATE TABLE mandatory_channels (
    chat_id     INTEGER PRIMARY KEY,
    title       TEXT    NOT NULL,
    invite_link TEXT    NOT NULL
);

-- 📦 Модталған қолданбалар
CREATE TABLE apps (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    app_name    TEXT    NOT NULL,
    description TEXT,
    version     TEXT,
    features    TEXT    NOT NULL,
    category    TEXT,
    file_id     TEXT    NOT NULL,
    file_name   TEXT,
    sha256      TEXT,
    vt_url      TEXT,
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 👥 Пайдаланушылар
CREATE TABLE users (
    user_id    INTEGER PRIMARY KEY,
    username   TEXT,
    first_name TEXT,
    last_name  TEXT,
    joined_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 📥 Жүктеу тарихы
CREATE TABLE downloads (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id       INTEGER NOT NULL,
    app_id        INTEGER NOT NULL,
    downloaded_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

> **✨ Автомиграция:** Бот ескі деректер қорын автоматты жаңартады — жетіспейтін бағандарды өз бетімен қосады.
